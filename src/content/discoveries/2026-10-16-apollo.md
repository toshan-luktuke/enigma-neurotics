## The short answer

The Apollo Guidance Computer stored its fixed programs in **core rope memory**. Wires passing through or around magnetic cores encoded information in a physical pattern.

## When a program had a shape

We usually think of software as something easy to copy or replace. Core rope memory made a program into hardware: the arrangement of wires represented the stored bits.

The computer also had erasable memory for information that needed to change. Fixed memory and working memory did different jobs, much as a program's instructions and its changing data do today.

## A practical choice

NASA's history of the computer describes core rope as a choice shaped by density and reliability. It also meant that changing the fixed program required producing a different memory module. Testing and manufacturing were part of getting the software ready to fly.

The next time an update downloads in the background, consider the difference. For Apollo, preparing a new fixed program involved making a new physical object. The code had to be right before that object went into the spacecraft.
